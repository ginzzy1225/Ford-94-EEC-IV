Bench check

With the Nano connected and nothing on the motorhome: the line should read idle (on the motorhome with the key off it may read ACTIVE; that's normal). Touch the STO lead to SIG RTN and it should read ACTIVE (and the Nano's L light comes on). "Ground STI" should make STI and SIG RTN read low ohms on a meter.

Key-on, engine-off test

  1. Engine warmed to operating temperature (a cold engine can set 116).
  2. Park, parking brake on, wheels blocked, A/C, defrost, lights and blower off.
  3. Key OFF for at least 10 seconds.
  4. Reader connected: STO, SIG RTN, STI.

Engine-running test

  1. Key-on codes fixed first (else the computer may refuse: code 998).
  2. Engine fully warm, then 2000-2500 rpm for 2-3 minutes.
  3. Engine OFF for 10 seconds. Park, parking brake, wheels chocked, loads off. Outdoors.

The screen, a beep and a vibration tell you when: right after the engine ID (4 flashes) turn the wheel half a turn and release, press and release the brake, press the O/D button on and off. If one single flash comes later, snap the throttle wide open once, briefly.

Erase memory codes

This erases the stored memory codes (Probst p. 228: release the self-test input once codes start). It doesn't erase the computer's learned adjustments.

  1. Park, parking brake, loads off. Key OFF for 10 seconds.

Wiggle test

Ford's continuous monitor test (Probst p. 225). After it starts, wiggle and tap one connector or harness at a time. Each time the computer sees a fault the screen flashes red and beeps. It erases memory codes: run the key-on test first.
